# Development and data origin

This is a new computational learning project prepared for Gaurang Agarwal's materials-engineering portfolio. Its code, tests, figures, and documentation were developed with AI assistance in this session. It is not a recovered coursework submission or a reconstruction of an earlier laboratory experiment.

All CSV files and plots in `results/` are deterministic simulation outputs regenerated by `run_study.py`. They are not measurements from a fabricated film. The diffusivity used to translate normalized time into seconds is an illustrative assumption, not a fitted or literature-validated value for a named material.

The background references explain diffusion and numerical methods. No experimental datasets, figures, or code were copied from them. The model schematic was drawn specifically for this project and depicts an idealized mathematical domain.

Local tests compare the numerical solver with an analytical series, check convergence and bounds, and verify thickness/diffusivity scaling. Those checks verify the implementation of the model; they do not establish agreement with experiments. Test execution and figures should be reproduced before quoting the repository's results.

The [walkthrough](WALKTHROUGH.md) explains how to reproduce the calculations and try an extension. Future contributions should record the changed assumptions, numerical settings, and checks.
